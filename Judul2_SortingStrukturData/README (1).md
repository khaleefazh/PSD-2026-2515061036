**Judul Program:** Pengurutan Tahapan Make Up

**Deskripsi Singkat:**
Program ini dibuat untuk mengurutkan daftar kosmetik agar sesuai dengan tahapan pemakaian yang benar. Menggunakan algoritma Bubble Sort, program akan membandingkan setiap produk dan menukarnya hingga urutannya logis dari langkah awal sampai akhir.

**Penjelasan Logika Kode Program:**
Logika program ini dimulai dengan fungsi "tukar" untuk memindah posisi elemen dan fungsi "urutan_makeup" yang memberikan bobot angka pada tiap produk (contoh: cushion bernomor 1, lipstik bernomor 7). Inti pengurutannya ada di fungsi "bubble_sort", di mana program melakukan perulangan untuk membandingkan prioritas produk yang bersebelahan; jika urutannya salah, maka posisinya ditukar. Terakhir, fungsi "main" menangani input dari pengguna, menjalankan proses sorting, dan menampilkan hasil urutan yang sudah rapi ke layar.
