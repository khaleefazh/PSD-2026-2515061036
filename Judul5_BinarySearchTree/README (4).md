Judul Program: 
Sistem Pengurut Nilai Kalori Menu Makanan di Cafe 

Deskripsi Singkat:

Jadi program ini gunanya untuk mengelola data kalori menu makanan di sebuah cafe dengan memakai struktur data Binary Search Tree (BST), lebih tepatnya disini menggunakan BST Lanjutan. Program bisa digunakan untuk menambahkan data, menghapus data, menampilkan isi tree, mencari tinggi tree, serta mencari rekomendasi menu dengan kalori yang sedikit lebih tinggi atau lebih rendah. Jadi data kalori akan tersusun otomatis dari nilai kecil ke besar hingga menjadi lebih rapi dan mudah dicari.

Disini ada class Node yang digunakan untuk menyimpan data kalori menu serta child kiri dan kanan. Selain itu ada class BSTLanjut juga yang isinya ada fungsi-fungsi utama kayak insert, delete, level-order, height, successor, dan predecessor. Fungsi insert digunakan untuk menambahkan data ke dalam tree sesuai aturan BST, sedangkan delete digunakan untuk menghapus data menu. Program juga bisa menampilkan isi tree berdasarkan level, menghitung tinggi tree, serta mencari nilai kalori yang sedikit lebih tinggi atau lebih rendah dari data tertentu.
